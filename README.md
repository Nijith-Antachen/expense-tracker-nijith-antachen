# Expense Tracker

A simple and responsive Expense Tracker web application built using HTML, CSS, and JavaScript.

The application allows users to manage their income and expenses, view their current balance, filter transactions, and keep their data saved using browser Local Storage.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Click **Get Started** to use the Expense Tracker.

No additional libraries or installations are required.
